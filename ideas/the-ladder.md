# The ladder: bit, local, pi, tenets

Four levels, each building on the last: exact (bit) -> finite (local) -> infinite (pi) -> deciding what's enough (the four tenets).

## Details

1. **Bit**: the smallest exact value, one light, lit or dark. Active-low: lit = 0, dark = 1.
2. **Local**: one finite machine. Nothing outside it, no network hops.
3. **Pi** (π, 3.14159…): infinite, never-ending, non-repeating. No computer can hold it exactly, only round it.
4. **Tenets**: all previous types, judged by Cost, Bridge, Work, Theory, decide how many digits are enough. More precision costs compute (Cost bit); trusting a rounded value unchecked raises the Theory bit. Goal `0000` = AI online.
